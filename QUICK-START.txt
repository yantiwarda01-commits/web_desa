================================================================================
   TROUBLESHOOTING
================================================================================

Problem: 500 Error
Solution: 
  1. Wait 60 seconds for MySQL
  2. docker-compose -f docker-compose-simple.yml restart webserver
  3. Check: http://localhost:8080/debug-info.php

Problem: Container Unhealthy
Solution:
  docker-compose -f docker-compose-simple.yml down -v
  docker-compose -f docker-compose-simple.yml up -d

Problem: Port Already Used
Solution:
  netstat -ano | findstr :8080
  taskkill /PID <PID> /F

Problem: Database Not Initialized
Solution:
  docker exec -i desa-mysql mysql -u root -proot_password_secure_2024 db_desa_sejahtera < database.sql
